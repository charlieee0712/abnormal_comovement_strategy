## 三、列 / 格式
- **`ticker`**:整数,去后缀去前导零(`600000.SH→600000`、`000001.SZ→1`),**与您公共库 `clc_ts_all_*` 完全一致** → 可直接按 `ticker + tradeDate` join。
- **`tradeDate`**:`YYYY-MM-DD`。
- **`weight`**:当日目标权重(**DEV 偏离约束**口径:个股 ≤ 1%、行业相对基准偏离 ≤ 3%、**不归一满仓**)。**每日权重和 = 当日仓位**(< 1、随信号数变 = 不满仓自带择时,非 bug;各候选日均仓位见上表)。池2 ⊂ 池1。

## 四、权重 / 回测口径(供对齐,执行可自定义)
- 权重为长仓、上述偏离约束;我们回测按 **5 日持有、6bp 双边成本**,基准 = 干净全市场等权(剔北交所/ST/次新近似)。
- `weight` 是**选股信号目标权重**;您可按自身持有 / 执行 / 再归一逻辑直接使用。

## 六、我们的读法(供参考,最终您定 / 自测)
- 想**四段稳、够分散** → **M_mean + veto**(旗舰)
- 想**低换手、吃近段** → **A4b + veto**(2024 段最强 13.23、换手最低)
- 想**最集中、最高信息比** → **M_union + veto**(2019-23 NW 到 6.26、持仓最少)

纯净版与 veto 版并给,方便您单看 cmf 否决这一层贡献了多少增量(近三段 +1.4~3.3、全段抬 NW)。

## 七、caveats(别当铁证)
1. 近段(2024-26)统计显著性偏弱:纯净版 NW 1.5–2.0,叠 veto 抬到 ≥2.1;n 小(~520 天)、以 2019-23 主段为主看。
2. 成本用 6bp;实盘预计 10–15bp,高换手候选(M_mean ~33x)更敏感。
3. 基准为干净全市场等权(量纯选股能力);alpha 偏中小盘、近段尤甚,评大盘版须换市值加权 / 大盘基准。
